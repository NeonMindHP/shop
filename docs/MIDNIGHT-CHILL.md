# Midnight Chill — Citynight Lounge

Published as Streaming product `midnight-chill` through the existing private R2 download flow. Six reduced JPEG previews show actual exports with labelled demo windows. The artwork follows the approved violet/blue Citynight concept; NeonMind lettering and personal portraits are absent from the graphics.

The package contains 65 PNG files, nine layered PSDs with 58 native editable text layers, twelve channel panels in 640 × 160 and 320 × 80, three webcam formats, four static alert cards, a profile banner, namestrips, text-free variants, source materials and German instructions. Scene headline pearl/violet gradients and outline/shadow styles are native Photoshop effects. Materials are separate raster layers.

Scene exports are 1920 × 1080; the generated Citynight source is 1672 × 941 and is scaled to the canvas. The package uses one violet/blue colour scheme. There are no animations, sounds, automatic alert events or account/device connections.

Checks cover every declared transparent aperture, opaque scenes, independent PSD composition and native text/effect parsing, archive integrity and the checksum of a downloaded copy of the uploaded ZIP. The optional Windows helper prepares seven image scenes for OBS import using absolute paths to the unpacked package. It does not edit existing OBS settings. The structure and source paths are checked; a live OBS session with the user's devices remains a user test.

Production scripts are in `tools/midnight-assets`; their private PNG inputs are supplied under `Quellen` in the customer ZIP. Generated customer files are excluded from the public repository. Existing shop checkout/test configuration is retained.
